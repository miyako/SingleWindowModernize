# 日本語デモ用の顧客データ（準備済み・未導入）

**現在の4Dデモにそのままインポートしないでください。** `FillData`は会社名から架空のWebサイトを作り、
顧客の信用や支払状況に関するランダムなコメントを追加します。実在する法人にこれらを関連付けないよう、
チェックポイント6で承認された改修が必要です。元の`demo/`、空のデータファイル、英語の顧客ファイルは変更していません。

## 出典と利用条件

国税庁法人番号公表サイト（国税庁）（https://www.houjin-bangou.nta.go.jp/download/zenken/）を加工して作成。

- 2026年9月30日時点の東京都の全件データ（CSV形式・Unicode、分割1・分割2）を使用しています。
- [利用規約](https://www.houjin-bangou.nta.go.jp/riyokiyaku/)と
  [公共データ利用規約（第1.0版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)に従ってください。
- 抽出・列の対応付け・日本国内所在地への国名付加は、このリポジトリで行った加工です。国税庁がこのデモや加工結果を作成・推奨したものではありません。
- HTTPSで取得したZIPのSHA-256を記録しています。ZIPに同梱されたPGP署名の検証は行っていません。

## 選択方法とファイル

東京都の会社（法人種別301～305）のうち、登記記録の閉鎖等年月日が空で、法人番号の取消し（処理区分99）ではなく、
最新履歴であるものを対象とします。商号又は名称・都道府県・市区町村・丁目番地等・郵便番号が揃うものを、
法人番号の昇順で200件選択しています。母集団を統計的に代表する標本ではありません。

| ファイル | 内容 |
|---|---|
| `Clients.txt` | ヘッダーなし、11列、タブ区切り、UTF-8（BOMなし）、LF。現在は配置候補であり、4Dには未導入です。 |
| `nta-selected.csv` | 選択した200件の公表CSVの全30項目を値のまま保存し、項目名のヘッダーを付加したものです。 |
| `provenance.json` | 出典、取得日時、スナップショット日付、元ZIPのハッシュ、抽出条件、件数、列対応、生成物のハッシュを記録しています。 |

`Clients.txt`の第N行は、`nta-selected.csv`のヘッダーを除いた第N行に対応します。
列順は、会社名、丁目番地等、市区町村、都道府県、郵便番号、国、電話、携帯電話、FAX、メール、担当者です。
国は国内所在地に基づく「日本」です。末尾5列は出典にないため空欄で、推測値は使用していません。
住所・社名・郵便番号の表記は加工せず、郵便番号の先頭ゼロも保持します。

商号イメージへの参照がある会社は`provenance.json`の`image_references`に記録しています。
公表CSVの文字列はそのまま保存していますが、登記上の字形と画像の照合は未実施です。字形を推測して補ってはいません。

このデータに実際の取引・請求・支払・信用評価・連絡先は含まれません。今後生成する取引は必ず**デモ用の合成データ**と明示し、
実在する会社の取引実績や信用を示すものと誤認されないようにしてください。税率・通貨・銀行情報の日本向け変更は行っていません。

## 再現と確認

リポジトリルートで実行します。標準ライブラリのみを使うNTA用アダプターで、既存のPDF処理には影響しません。

```sh
.venv/bin/python tools/nta_customers.py verify data/ja
.venv/bin/python tools/nta_customers.py fetch --snapshot 2026-09-30 --cache build/nta
.venv/bin/python tools/nta_customers.py prepare --manifest build/nta/download.json --output build/nta-reproduced
```

`prepare`は出力を上書きしません。元ZIPがキャッシュに残っていれば、全件を再走査して同じ200件を選択できます。
国税庁の公開スナップショットは更新されるため、将来同じZIPを再取得できるとは限りません。
元ZIPがない場合でも、コミットされた選択元CSVから11列TSVを照合できますが、
全件の先頭200件という選択の再確認には、記録されたハッシュと一致する両方の元ZIPが必要です。

文書中の通信量・パケット数は原著の測定例であり、このデータによる測定結果ではありません。
文書のコード、数値、英語スクリーンショットはこの準備段階では変更していません。
